Clase C

Redes pequeñas · Máscara 255.255.255.0 (/24)

Datos técnicos

  • Rango primer octeto: 192 – 223
  • Bits iniciales: 110
  • Máscara por defecto: 255.255.255.0 (/24)
  • Redes posibles: 2.097.152
  • Hosts por red: 254
  • Rango privado: 192.168.0.0 – 192.168.255.255

Uso y características

Redes pequeñas

La Clase C se utiliza para redes pequeñas, como una oficina o una casa. Es la más común en redes domésticas y en entornos donde no se necesitan demasiados hosts por subred.

Los tres primeros octetos identifican la red; solo el último octeto queda para hosts.
